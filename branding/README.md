# Mesh Hub branding

| File                          | Use                                                   |
| ----------------------------- | ----------------------------------------------------- |
| `mesh-hub-wordmark-dark.svg`  | Wordmark for dark backgrounds (white "Mesh")          |
| `mesh-hub-wordmark-light.svg` | Wordmark for light backgrounds (charcoal "Mesh")      |
| `mesh-hub-icon-1024.png`      | Square app icon master (orange "hub" box on charcoal) |

The wordmark is a vector trace of the original artwork. The app icons in `resources/icons/`
are generated from the same "hub" box, and the in-app logo is
`src/renderer/components/MeshHubWordmark.tsx`.

Colors: Signature Orange `#FFA31A`, black `#000000` on the box, white `#FFFFFF` or
charcoal `#1B1B1B` for "Mesh".
